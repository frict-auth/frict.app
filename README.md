# frict.app

The privacy policy of the Frict Android app at https://privacy.frict.app/, served by GitHub Pages from the root of `main`: hand-written HTML with no build step. The app and its server live in [frict-android](https://github.com/frict-auth/frict-android) and [frict-server](https://github.com/frict-auth/frict-server).
