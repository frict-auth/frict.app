# frict.app

The website at https://frict.app, served by GitHub Pages from the root of `main`: hand-written HTML with no build step. It holds the privacy policy of the Frict Android app at https://frict.app/privacy/. The app and its server live in [frict-android](https://github.com/frict-auth/frict-android) and [frict-server](https://github.com/frict-auth/frict-server).
